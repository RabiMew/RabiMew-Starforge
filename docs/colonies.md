# 殖民人口与驻军

本文件是设计行为规范，不是模组配置说明。守卫行为、环境保护与枪械兼容均需游戏内实测，未验证项见[兼容性核查](compatibility.md)的适配清单。

## 1. 定位

殖民地 = 玩家建立的工业化外星前哨站 + 少量居民 + 自动生产设施 + 武装警卫 + 炮塔 + 后勤网络，不是城市模拟。核心关系：**工业系统养活殖民地，工业军工武装守卫，守卫与炮塔保护工业**；NPC 系统不取代整合包其他部分。

不引入：MineColonies、MCA Reborn、TACZ NPCs（除非未来确实出现 Guard Villagers 无法满足的敌对 NPC 需求）、大型 RPG NPC 系统、第二套重复的大型战术装备系统。

居民的作用是“这里真的有人生活”，不能成为服务器最大的 CPU 来源。设计目标（非模组硬限制）：小型前哨 2–8 个活动居民/守卫，中型基地 8–20，大型殖民基地 20–40；不鼓励上百士兵同时巡逻。

## 2. 居民与 Easy Villagers

Easy Villagers 在此承担**抽象化殖民设施**：用设施化居民减少村民寻路、床位竞争、工作站竞争、农田 AI 和大量自由活动实体。任务文本可把 Farmer 解释为殖民农业设施、Breeder 为居住与人口中心、Trader 为殖民贸易设施、Iron Farm 为自动化基础材料设施——这些仅是 Starforge 世界观解释，不篡改第三方 Mod 的名称和语言文件。

第一批居民必须来自地球：村庄招募/搬运村民 → Easy Villagers 运输 → 火箭送至殖民地 → 建立居住区 → 以人口设施扩展。第一批外星殖民者不凭空生成；“把人类送到另一个星球长期定居”本身就是 T6 航天殖民的重要里程碑。

不做人口 grind：殖民成熟度取决于能源、氧气、食物、工业、库存、物流与防御，而非人口数量。

## 3. Guard Villagers 驻军

守卫 = 殖民警卫/民兵/驻军，职责是巡逻、保护居民、建筑内部防守、补足炮塔死角、对抗少量渗透怪、协助玩家处理怪潮、保护温室/仓库/居住舱等内部设施。

分工：守卫可以战斗；普通居民不参加大型怪潮，优先躲避 → 进入安全区 → 留在建筑内部。

## 4. 三层防御体系

| 层 | 承担者 | 负责 |
| --- | --- | --- |
| 一：固定防御 | Defense Turrets | 基地外围、主火力线、大规模怪潮、AoE、装甲目标、长时间持续射击 |
| 二：殖民步兵 | Guard Villagers + TaCZ | 建筑内部、街道、炮塔死角、渗透与少量突破单位、侧翼、防线破口 |
| 三：玩家 | 玩家 | 工程兵、精英怪、Boss、装甲目标、战线崩溃、紧急维修、高价值目标 |

没有任何一层应单独解决整个怪潮。

## 5. 单兵军工

TaCZ 是 Starforge 工业体系的**军事消费端**，不是独立枪战科技树。武器制造接入 IC2 精炼、IE 金属加工、石油化工、AE2 与 BuildCraft 物流；不允许“木头 + 铁锭 → 终局步枪”。

首轮核心武器控制在约 10–15 种，目标是战术角色差异而非军火收藏：手枪只留少量差异明显型号；步枪体现近距/通用/精确分工，不做 AK-A 到 AK-E 式的同质堆叠。

| 阶段 | 武器 | 定位 |
| --- | --- | --- |
| T0 | 剑、弓、弩 | 民兵 |
| T1 | 基础手枪、基础霰弹枪 | 聚落警卫 |
| T2 | SMG、基础步枪、基础霰弹枪 | 正式基地警卫 |
| T3 | 突击步枪、精确步枪、改良弹药 | 工业化殖民驻军 |
| T4 | LMG、高威力步枪、重型霰弹、少量特殊弹药 | 重工业军备 |
| T5 | 高级工业枪械、少量高科技枪械、IE Railgun 等重型个人武器 | 原子时代军备 |
| T6 | 外星殖民驻军 | 重点是可靠、弹药供应、环境适应与防御协同，不一定是更高伤害 |
| T7 | 高级能源武器候选、纳米装备守卫候选、极少数精英警卫 | 不给所有 NPC 批量发终局装备 |

IE 武器保留独立定位，不被 TaCZ 淘汰：左轮 = 可靠工业副武器；Chemthrower = 化学/AoE/工业用途；Railgun = 重型电磁/反装甲，面向重甲、精英与大型敌人——普通怪物用自动步枪处理更经济，不把 Railgun 做成“伤害更高的步枪”。

### 护甲梯度

暂不加入大型战术护甲 Mod，复用原版 / IE / Ad Astra / IC2CRE：T0 皮革/铁（民兵）；T1–T2 铁甲与 IE 钢制装备候选（基地警卫标配）；T3–T4 高级工业护甲（更高护甲/耐久、盾牌、特定重装单位，但不让每个 NPC 都成坦克）；T5–T6 Ad Astra 航天装备承担环境防护；T7 IC2 纳米护甲可作精英警卫候选，量子护甲主要留给玩家。

武器与护甲不是同一条升级线：不做“科技越高 = 所有守卫同时更高伤害 + 更高护甲 + 更高血量”的指数膨胀。按职业区分：普通警卫（中等武器/护甲）、射手（高射程/低至中护甲）、重装（重护甲/低机动）、支援（普通武器/内部安全）。

## 6. 弹药与补给后勤

军工链：矿石 → IC2 精炼 → IE 金属加工 → 枪械零件 → TaCZ 武器；弹药 = 铜/铅/钢 + 火药/化工材料 → 弹头/弹壳 → 弹药，成组产出；高级弹药加入高级合金、石油化工材料、IE 加工与 IC2 电力组件。弹药不是“一个铁锭无限生成”。

两条军事物流：军工厂 → 弹药库存 → 炮塔；军工厂 → 步兵弹药库存 → Guard Villager。守卫补弹优先使用 Guard Villagers TACZ Support 原生的“从附近箱子/木桶寻找弹药”机制，不重复开发另一套 NPC 补弹 AI。

AE2/BC 链路：生产线 → AE2 主库存 → 阈值检测 → 前线缓冲箱 → BC/实体物流 → 弹药箱 → 守卫。前线始终保留本地库存：网络中断 ≠ 整个基地瞬间失去战斗力，不让守卫每开一枪都访问跨星球网络。

殖民军工补给复用现有仓储体系：Storage Drawers 承担大宗原料、Sophisticated Storage 承担弹药/食物/零件缓冲、AE2 承担库存管理与自动生产、BC 承担物理运输——不建第四套殖民仓储。殖民地跨设施的大宗运输（矿场 → 氧气区 → 工业区 → 发射场）由 Railcraft 铁路承担，与地球基地同一套物流层级。

## 7. 各星球驻军风格

| 区域 | 驻军风格 |
| --- | --- |
| 地球 | 基础殖民警卫 |
| 月球 | 少量守卫，紧凑舱室防御 |
| 火星 | 高怪潮压力；守卫是第二防线，外围必须依赖炮塔 |
| 金星 | 强调密闭安全区 |
| 水星 | 科研/采矿前哨，少量精锐守卫 |
| 霜原星 | 重装怪多，需要穿甲、Railgun 与激光塔 |
| 空间站 | 可有守卫，但保持无自然怪物、无自动怪潮；守卫承担安保与特殊事件 |
| 小行星带 | 无常驻驻军：无氧真空 + 低重力的采矿远征区，按远征队模式携带装备往返；结构内部敌人属结构内容 |

## 8. 与农业和威胁值的关系

居民与守卫让食物系统保持价值：农业 → 厨房 → 食物仓库 → 殖民居民 → 殖民守卫；若 Guard Villagers TACZ Support 存在低血量寻找食物机制，需实测其实际使用行为。

威胁值 H 不采用“每个守卫 +5 / 每把枪 +5”：人口与驻军本身不直接显著抬高威胁，避免“不养居民、不造守卫”成为最优策略。大规模军工生产会自然通过生产耗能、批次与物流活动提高 H。未加载殖民地处于摘要状态：NPC 不继续完整 AI、不巡逻、不找弹药、不搜索敌人、不主动强加载区块。
