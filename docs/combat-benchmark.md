# Combat Benchmark 测试清单

状态：**设计目标清单**。所有数值为首轮校准目标，须在实际枪械与模组数据上实测修正；未测前不填精确结论，不冒充已通过。

## 1. 标准战斗基准

每个科技阶段选定一套基准样本并实测：

- 1 把该阶段标准枪
- 1 套该阶段标准护甲
- 1 个该阶段标准守卫
- 普通怪 / 快攻怪 / 工程兵 / 重装怪各 1 个

每次测试记录：

| 武器侧 | 怪物侧 |
| --- | --- |
| 单发伤害、射速 | 移动速度 |
| 弹匣容量、换弹时间 | 攻击间隔 |
| 一弹匣持续 DPS、含换弹持续 DPS | 护甲/抗性表现 |
| 10 / 20 / 30 格命中率 | 路径与绕侧行为 |
| 爆头伤害、护甲后的实际伤害 | 特殊能力 |

不只比较武器 Tooltip Damage。

## 2. TTK 首轮目标（待实测校准）

同阶段、正常装备的 Guard Villager 对单目标：

| 目标 | 首轮 TTK 目标 | 设计意图 |
| --- | --- | --- |
| 普通怪 | 约 2–4 秒 | 普通怪必须能被枪械有效处理 |
| 快攻小型怪 | 约 1–3 秒 | 压力来自数量、速度与绕侧 |
| 工程兵 | 约 5–9 秒 | 单守卫不瞬秒工程兵，玩家有理由优先集火 |
| 装甲重型单位 | 单守卫约 10–18 秒 | 多守卫集火明显加快；迫使使用 Railgun / 穿甲弹 / 激光塔 / 重火力，而不是多打几百发普通子弹 |
| 小型 Boss / 精英 | 不被一名 NPC 一弹匣秒掉 | 4 名同阶段守卫 + 基地火力仍需持续战斗；具体秒数实测后填写，不填虚假精度 |

## 3. 反向 TTK：怪物攻击守卫

- 同阶段普通守卫暴露在防线外不能无限抗怪。
- 一个普通同级敌人击杀守卫需较长时间；2–3 个普通敌人包围后明显危险；重型/精英单位能快速威胁孤立守卫。
- 目的：守卫需要掩体、队友、炮塔、玩家和防线，而不是站在空地单刷整个怪潮。

## 4. 平衡原则

强度提升顺序：**战术组合 > 数量 > 路线 > 移动速度 > 护甲 > 特殊能力 > 生命值**。普通怪不随 T0→T7 无限加血（T7 僵尸不应有 500 HP）；需要耐打时优先护甲、抗性、正面防护、特定弱点、低移动速度（例：重装怪高护甲、低移速、明显弱点、惧怕 Railgun），不做“1000 HP 普通僵尸”式血牛。

加入 TaCZ 后必须重新完整平衡：不沿用“原版怪物血量 + 高 DPS 自动步枪”（怪瞬间失去威胁），也不反过来“所有怪物生命 ×10”（无反馈血牛）。

## 5. 机制核验

- TaCZ 实测：护甲如何计算、爆头如何计算、枪械穿透、不同弹药穿甲差异、模组护甲是否正确参与。
- 若 TaCZ 对 IE / IC2 / Ad Astra 护甲处理不正确：记录兼容问题，必要时增加 Starforge Combat Compatibility 小型适配层；不为平衡简单改所有装备基础 Armor 值。
- 炮塔与步兵相对输出：一个基础炮塔应明显强于一个普通守卫的持续防区控制，但不能达到“一塔 = 20 守卫”；守卫 = 灵活，炮塔 = 高持续火力，玩家 = 高爆发与战术能力。

## 6. 怪潮预算重校准

`B = 12 + 0.8 * H` 保留为首轮框架，但加入自动枪械后单位成本必须重测：不假定普通 1 / 工程兵 3 / 重型 6 仍然合理。用一个标准 T3/T4 基地（2–4 守卫 + 1–2 炮塔 + 1 玩家）做波次实测后再调预算。

| # | 场景 | 目的 |

**记录指标**（每场必记）：服务端 MSPT、TPS（`/neoforge tps` 或 spark）、客户端 FPS、实体数、弹丸数（`/kill` 前后对比或 spark 实体视图）、在场炮塔数、弹药消耗（箱内前后差值）、击杀速度（波次清空时间）。

**判定**：若某把 EOS 武器产生大量常驻实体/粒子/特殊弹丸导致 MSPT 或 FPS 明显劣化，单独调整或限制该武器（如限制弹药补给、阶段上调、配方加价），而不是削减整个怪潮规模。`eos:eoslab_12g` 上游无配方（视同禁用），不参与基准。

## 7. 敌方持枪单位

- T0–T2：自然敌人不使用枪械。
- T3：怪潮可极少量出现射手/掠夺者枪手。
- T4–T5：允许步枪手与远程压制单位，首轮上限约 **10% 战斗预算**。
- T6–T7：特殊行星/高威胁基地可略升，首轮上限约 **15%**；具体比例实测调整。
- 禁止整个怪潮每只僵尸都拿自动步枪；默认不让自然生成怪随机获得枪。
- 敌方枪械配置限制射速、精度、弹药、射程、连射长度：普通枪手中低精度、精英枪手更准确、Boss 可用特殊攻击；普通僵尸不得 30 格全自动爆头。

## 8. 胜负与弹药经济

- 建设合理、弹药充足的基地应能守住大部分正常怪潮；完全 AFK 不应是默认最优解。
- 工程兵、Boss、侧翼突破、电力中断、弹药耗尽等情况需要玩家处理。
- 每场怪潮消耗弹药、电力、食物、装备耐久与维修需求；怪物掉落不能完全覆盖成本，避免“怪潮 → 弹药资源 → 免费下一场”的正收益循环。

## 9. 守卫行为验收（Guard Villagers TACZ Support）

逐项实测并记录结果：

- 远距离寻找敌对单位
- 正确射击 TaCZ 武器
- 消耗对应弹药、使用 TaCZ Ammo Box
- 从箱子/木桶等库存寻找弹药
- 缺少生命值时寻找食物
- 调整位置获得射界
- 尽量避免向友方实体开火
- Zombie / Pillager 持枪能力（默认关闭自然随机配枪）

## 10. 外星环境矩阵

月球 / 火星 / 金星 / 水星 / 霜原星 / 空间站逐一测试：氧气、温度、真空与环境伤害、寻路、枪械射击与弹道、炮塔识别、怪物仇恨。地球测试结果不外推到其他星球。

## 11. NPC 装备环境生效性

- 完整 Ad Astra 航天装备 + 氧气供应下的 Guard Villager：真空、氧气、温度、星球环境伤害是否实际生效，逐项实测；若仅对 Player 生效，优先小型兼容层（完整航天服 + 有效供氧 → 守卫获得对应保护）；无法可靠实现时，外星守卫限定部署在已供氧/已密封殖民区。
- IC2 纳米/量子护甲发给 NPC 前实测：充能使用、防御属性、特殊能力稳定性与平衡；量子护甲默认主要留给玩家。
